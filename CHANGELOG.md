# Changelog

## 2026-11-18

- Added a logo-inspired illustrated background to the idle workspace in the Zombie Green theme.
- Added a Yes or No confirmation when closing the manager with open RDP connections. No is the default.
- Reduced the height of the status bar.
- Fixed Auto fit sending odd pixel widths to RDP. Fixed-resolution requests now wait for the remote desktop to confirm the requested size. The manager keeps the current display mode when a request is rejected or unconfirmed.
